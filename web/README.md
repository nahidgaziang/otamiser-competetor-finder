# Competitor Hub & Editorial Review Interface

Web frontend and administrative dashboard built with Astro SSR and Node.js.

## Overview
- **Public Comparison Hub:** Serves verified competitor comparison overviews and structured feature breakdown grids.
- **Admin Review Dashboard:** Allows human editors to inspect research claims, edit comparison drafts, verify source evidence quotes, and manage publication states.

## Development

```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
